# Kazesawa font notice

Kazesawa is distributed under the SIL Open Font License 1.1 and is built from
M+ and Source Sans Pro components.

Official project:
https://github.com/kazesawa/kazesawa

If you add Kazesawa font binaries to `public/fonts/`, preserve the license and
notice files that accompany the exact Kazesawa release you downloaded.
The upstream release process explicitly bundles Kazesawa's `LICENSE.txt` plus
license/readme files for the M+ and Source Sans Pro source fonts.

For that reason, this repository does not attempt to replace those upstream
release notices with a simplified local copy. Copy the accompanying license
files from the same official Kazesawa release alongside the font binaries,
for example under:

    licenses/fonts/kazesawa/

This is especially important if you redistribute the font files from this
repository or from packaged releases of this application.

Presentation Timer - local font setup
=====================================

Font binaries are NOT included in this repository.
Place appropriately licensed font files in this folder if you want to serve
them from the Presentation Timer server.

Recommended filenames
---------------------
Jost:
  Jost-VariableFont_wght.woff2
or
  Jost-VariableFont_wght.ttf

Kazesawa:
  Kazesawa-Regular.woff2
or
  Kazesawa-Regular.ttf

Optional bold Kazesawa:
  Kazesawa-Bold.woff2
or
  Kazesawa-Bold.ttf

You do not need to install the fonts on each device. Once placed here, the
server provides them as Web fonts to connected PCs and phones.

WOFF2 is preferred when both WOFF2 and TTF are present.

Licensing
---------
If font binaries are committed to GitHub or redistributed with the app, also
commit the license/copyright notices from the same upstream font release.

See:
  ../../THIRD_PARTY_NOTICES.md
  ../../licenses/fonts/

For Kazesawa in particular, preserve the accompanying notices for Kazesawa,
M+, and Source Sans Pro from the official release package.
